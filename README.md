#### *Superstore Sales Analysis Dashboard*

##### 

###### *This project analyzes Superstore sales data using Microsoft Excel.*

###### 

###### ***Tools Used***

###### 

* *Microsoft Excel*
* *Data Cleaning*
* *Formulas*
* *Charts*



###### ***Analysis Performed***

###### 

* *Sales by Region*
* *Profit by Category*
* *Top Product Analysis*
* *Dashboard Creation*



###### ***Key Insights***



* *West region had the highest sales.*
* *South region had the lowest sales.*
* *Office Supplies was the most profitable category.*
* *Furniture generated a loss.*
* *Machines was the best selling product.*
